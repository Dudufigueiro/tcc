# Frontend – Carga Horária Docente

Vue 3 + Quasar (app-vite). Veja o README da raiz do projeto para instruções completas.

```bash
npm install
npm run dev     # http://localhost:9000 (proxy de /api para http://localhost:3000)
npm run build   # saída em dist/spa
npm run lint
```

Para apontar o proxy de desenvolvimento para outra API: `API_PROXY_TARGET=http://host:porta npm run dev`.
